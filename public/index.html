    About & Methodology

    Historical probabilities are computed from available observations/reanalysis for the selected location and period. They are not guarantees and not a substitute for official forecasts or warnings.

    • Historical data source: Open-Meteo Archive API (daily temperature max/min/mean, precipitation sum, wind max). Provider/type are shown in analysis metadata; values are API-delivered historical weather/reanalysis data, not presented as direct NASA product downloads.
    • Forecast data source: Open-Meteo Forecast API (separately labeled short-term forecast).
    • NASA resources used directly: GIBS WMTS imagery layer (MODIS Terra Corrected Reflectance True Color) on the interactive map; plus research/discovery links to Worldview, Giovanni, GES DISC, and Earthdata Search.
    • Not implemented as live browser data: direct authenticated NASA GES DISC/Giovanni dataset queries and fabricated "NASA atmospheric/surface/hydrological" random values from the old prototype were removed. Where direct browser integration is impractical, the app provides documented research links and transparent limitations.
