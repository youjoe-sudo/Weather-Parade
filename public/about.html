About Weather Parade

Weather Parade helps users evaluate historical weather patterns for outdoor event planning. It focuses on historical probability from available observations, not deterministic long-range forecasting.

Data sources

  • Open-Meteo Forecast API — short-term forecast.
  • Open-Meteo Archive API — historical daily weather/reanalysis values used for probability calculations.
  • OpenStreetMap/Nominatim — geocoding and base map tiles.
  • NASA GIBS — MODIS Terra Corrected Reflectance imagery layer.
  • NASA Worldview, Giovanni, GES DISC, Earthdata Search — research/discovery links.

Scientific honesty

The app does not fabricate NASA observations. Historical probabilities are computed from valid API-delivered observations with sample counts and thresholds shown. Some NASA services require authentication or server-side workflows; those are documented rather than faked.
